Replace a range of lines (or a single line) in a text file, targeted by 4-character anchors from read output. Saw `Hasu│content` in read/diff/anchor_grep: `Hasu` is the bare HASH before `│`, `Hasu│content` is the full row. `remove_from` and `remove_to` are bare HASH only (e.g. `"Hasu"`), never the full row or file content. `replacement_lines` is bare content without `│`, one string per line — use `[]` to delete. Example: read showed `Hasu│old` and `arvm│old2`, to replace both use `{"remove_from":"Hasu","remove_to":"arvm","replacement_lines":["new line 1","new line 2"]}`. Single line → same anchor for both.
