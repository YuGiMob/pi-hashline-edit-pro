Undo the last `replace` or `insert` on a file, restoring previous content, BOM and line endings. Use after a bad edit removed wrong lines. Deleted file → restored; changed elsewhere → `[E_UNDO_STALE]`, nothing reverted, record kept — do not modify the file to force an undo; `read` to verify, then stop. If output says truncated, use `read` to see full file.
