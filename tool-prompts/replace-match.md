Replace part of a line — or the same fragment on several lines of a range — without retyping the rest. `match` is the exact text to find inside the anchored range, and `replacement` replaces every occurrence; the text around each match is left untouched. An occurrence embedded in a larger identifier is refused with `[E_MATCH_NOT_ISOLATED]` before anything is written: each edge of `match` must sit at a line edge or next to a character that cannot continue an identifier, and letters, digits, `$`, `_`, and Unicode identifier characters all continue one. Pass `allowEmbeddedMatch: true` when replacing a fragment inside an identifier is intended. `match` stays within one line, while `replacement` may span lines (a single trailing line break is its terminator); new lines inherit the file's line endings. Send only the fragment that changes — never text that `replacement` leaves unchanged — and narrow `replace_from`/`replace_to` when only one occurrence should change. For a whole-line rewrite, use `replace` with the same anchors.

The two boundary anchors must still match what was last shown; lines strictly inside the range are searched as they are on disk.
